# Big-Billion-Days-Analytics
## Project Objective

This project analyzes Flipkart's Big Billion Days sales performance using SQL, spreadsheets, and dashboard planning.

The objective is to evaluate regional revenue, product performance, order statuses, and sales representative performance while ensuring data accuracy and producing actionable business recommendations.

## Tools Used

- **SQL:** Data querying and analysis
- **Google Sheets:** Data cleaning, calculations, and pivot tables
- **Dashboard:** KPI and chart planning
- **GitHub:** Project documentation and version control
## Project Workflow

1. Data understanding and business analysis
2. SQL database creation and analysis
3. Spreadsheet data cleaning and analysis
4. Dashboard planning and visualization
5. AI-assisted verification and documentation
6. Final validation and GitHub submission

## Key Business Questions

1. What is the total revenue from completed orders?
2. Which products generate the highest revenue?
3. How does revenue vary across regions?
4. What is the distribution of orders by status?
5. Which sales representatives meet their monthly targets?
6. Which customers and regions contribute most to sales?
7. Are there missing values or data-quality issues?
8. How does monthly sales performance change over time?
